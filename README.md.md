# پروژه سیستم مدیریت ارسال و تحویل (Delivery System)

## معرفی

این پروژه یک سیستم مدیریت ارسال و تحویل مبتنی بر خط فرمان است که با زبان پایتون پیادهسازی شده است. سیستم امکان ثبت رانندگان، ایجاد سفارشها، تخصیص سفارش به رانندگان، بهروزرسانی وضعیت سفارشها و انجام کوئریهای مختلف را فراهم میکند.

---

## راهنمای اجرا

### پیشنیازها

- Python 3.7 یا بالاتر (به دلیل استفاده از `from __future__ import annotations` و تایپهینتها)

### اجرا

```bash
python main.py
```

سپس دستورات را از ورودی استاندارد (stdin) وارد کنید. برای پایان، دستور `END` را وارد کنید.

### مثال اجرا

```bash
python main.py << EOF
ADD-DRIVER Ali (0, 0) BIKE
CREATE-ORDER BIKE (1, 1) (5, 5)
ASSIGN-NEXT-ORDER Ali
GET-DRIVER Ali
END
EOF
```

## معماری پروژه

پروژه از معماری لایهای پیروی میکند و هر فایل مسئولیت مشخصی دارد:

```text
├── main.py              # لایه رابط کاربری (UI) — فقط پارس دستورات و چاپ خروجی
├── delivery_system.py   # لایه منطق کسب‌وکار (Business Logic)
├── driver.py            # مدل راننده
├── order.py             # مدل سفارش
└── validators.py        # توابع اعتبارسنجی مشترک
```

### توضیح فایلها

| فایل | مسئولیت |
|------|----------|
| `main.py` | رابط متنی؛ هیچ منطق کسبوکاری ندارد. فقط دستورات را پارس میکند `DeliverySystem` را فراخوانی میکند و نتایج را قالببندی میکند. |
| `delivery_system.py` | مغز سیستم؛ مدیریت رانندگان، سفارشها، اعتبار شرکت و تمام عملیات اصلی. |
| `driver.py` | کلاس `Driver` با وضعیتها (`FREE`, `BUSY`) و منطق جابجایی. |
| `order.py` | کلاس `Order` با وضعیتها (`PENDING`, `ARRIVED`, `PICKUP`, `DELIVERED`). |
| `validators.py` | توابع اعتبارسنجی مانند `validate_position`, `manhattan`, `validate_category` و غیره. |

### جریان داده

```text
ورودی کاربر → main.py (پارس) → DeliverySystem (منطق) → خروجی قالب‌بندی‌شده
```

## دستورات پشتیبانیشده

### مدیریت رانندگان

- `ADD-DRIVER <username> (<x>, <y>) <category>` — افزودن راننده جدید
- `GET-DRIVER <username>` — دریافت اطلاعات راننده
- `GET-DRIVER-LIST <status>` — لیست رانندگان با وضعیت مشخص (`FREE` / `BUSY`)

### مدیریت سفارشها

- `CREATE-ORDER <category> (<sx>, <sy>) (<fx>, <fy>)` — ایجاد سفارش جدید
- `ASSIGN-NEXT-ORDER <username>` — تخصیص نزدیکترین سفارش در انتظار به راننده
- `ORDER-UPDATE <status> <username> <order_id>` — بهروزرسانی وضعیت سفارش
- `GET-ORDER <order_id>` — دریافت اطلاعات سفارش
- `GET-ORDER-LIST <status>` — لیست سفارشها با وضعیت مشخص

### کوئریهای مکانی

- `GET-NEAR-DRIVER (<x>, <y>) <n>` — نزدیکترین رانندگان آزاد
- `GET-CNT-ORDER (<x>, <y>) <distance> <START|FINISH>` — شمارش سفارشها در محدوده
- `GET-NEAREST-PENDING-ORDER (<x>, <y>)` — نزدیکترین سفارش در انتظار

### اطلاعات مالی

- `GET-COMPANY` — اعتبار شرکت

### قابلیت امتیازدهی (خلاقانه)

- `GIVE-DRIVER-SCORE <username> <score>` — ثبت امتیاز (۱ تا ۵) برای راننده
- `GET-DRIVER-SCORE <username>` — دریافت میانگین امتیاز راننده

### پایان

- `END` — خاتمه اجرا

## دستور اجرای تست

پروژه از `unittest` برای تست استفاده میکند.

برای اجرای تستهای عمومی فایل `test_contract`:

```bash
python -m unittest test_contract -v
```

```bash
python -m unittest discover -s tests -v
```

تمامی تست های مستقل و عمومی با موفقیت اجرا شدند و پیام (ok) دریافت کردند. تست کوئرا هم با فایل `for_quera_test.py` اجرا شد که هر 10 تست را با موفقیت به پایان رساند.

## توضیح قابلیت جدید خلاقانه: سیستم امتیازدهی رانندگان (Driver Scoring System)

### هدف

قابلیت امتیازدهی به رانندگان به مشتریان (یا سیستم) اجازه میدهد تا کیفیت خدمات هر راننده را ارزیابی کنند. این امتیازها در میانگینگیری ذخیره شده و میتوانند مبنای تصمیمگیریهای آینده باشند.

### نحوه کار

1. هر راننده لیستی از امتیازهای دریافتی دارد (در `Driver._scores`).
2. با فراخوانی `GIVE-DRIVER-SCORE`، یک امتیاز بین **۱ تا ۵** به راننده اضافه میشود.
3. امتیاز خارج از بازه باعث خطا میشود.
4. با `GET-DRIVER-SCORE`، میانگین امتیازها با یک رقم اعشار بازگردانده میشود (مثلاً `3.7`).
5. اگر راننده هیچ امتیازی نداشته باشد، خروجی `no score` است.

### نمونه استفاده

```text
GIVE-DRIVER-SCORE Ali 5
GIVE-DRIVER-SCORE Ali 5
GIVE-DRIVER-SCORE Ali 1
GET-DRIVER-SCORE Ali
# خروجی: 3.7
```

### پیادهسازی

- `Driver._add_score(score)` — افزودن امتیاز به لیست
- `Driver.score` — property محاسبه میانگین
- `DeliverySystem.give_driver_score(username, score)` — اعتبارسنجی و ثبت
- `DeliverySystem.get_driver_score(username)` — بازگرداندن میانگین یا `None`
